# SI401 – Programação para a Web · Site da Disciplina

Site desenvolvido como atividade das **Unidades 02 a 08** da disciplina
**SI401 – Programação para a Web** (Faculdade de Tecnologia – Unicamp, 2º semestre de 2026).

O projeto é uma versão preliminar do site da disciplina, usando apenas os conteúdos vistos em aula: HTML5 semântico e CSS em folha externa.

## Páginas

| Página | Conteúdo |
|---|---|
| `index.html` | Informações gerais, ementa, objetivos, competências e Plano de Ensino |
| `cronograma.html` | Tabela com datas, unidades, conteúdos e objetivos das aulas |
| `atividades.html` | Atividades de fixação, entregas do Projeto Final e cálculo da média |
| `materiais.html` | Slides por unidade e bibliografia básica e complementar |
| `docente.html` | Professor responsável e PED |

## Tecnologias

- HTML5 com elementos semânticos (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- CSS3 em folha de estilos externa (box model, grid, flexbox, position)
- Sem JavaScript, frameworks ou bibliotecas

## Como executar

Baixe ou clone o repositório e abra o `index.html` em qualquer navegador.
Não é necessário servidor nem instalação.

## Validação

Os arquivos HTML e CSS foram validados nos validadores do W3C.
